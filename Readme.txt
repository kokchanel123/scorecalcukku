สวัสดีครับผม ผมชื่อนายภูมิพัฒน์ สุขตะกั่ว ผมได้ทำ project python เล็กมากๆไม่ได้ใช้เทคนิคอะไรมากมาย เพื่อเอาไว้ใช้ในการคำนวณคะเเนนของส่วนตัวผมเอง เพื่อใช้ในการจะทำคะเเนนnetsat รอบต่อไป เเละยังช่วยฝึก coding 
ทั้งที่ผมเเทบจะไม่มีเวลาทำ ผมวางเเผนไว้ว่าจะเพิ่มระบบต่างๆหรือไม่ก็ทำให้ ui ให้สวยกว่านี้โดยอาจจะหันไปฝึกใช้ react ไม่ก็ kivymd เเต่เนื่องจากผมไม่มีเวลามากมายมีงานเยอะมาก อ่านเตรียมสอบด้วยเเละผมก็วางเเผนไว้ว่าจะทำproject อื่นด้วย
ผมจึงหวังว่างานชิ้นนี้จะมีประโยนช์กับใครต่อไปเเละงานชิ้นนี้ทำให้ผมได้เรียนรู้สิ่งต่างๆเยอะมากสำหรับผมขอบคุณครับ 
ระยะเวลาที่ได้ทำ : 06/06/2025 - 30/06/2025
เครื่องมือที่ใช้: python ,kivy 
ปัญหาที่่เจอ: การจัดการข้อมูลให้เขียนง่ายขึ้นอย่างมีระบบ ให้โค้ดดูประสิทธิภาพมากกว่านี้ผมรู้สึกมันมีวิธีลดเวลาทำเเต่ละสาขาให้น้อยลงได้มากกว่านี้ เเต่ผมก็คิดได้เเต่วิธีนี้จริงๆ
สิ่งที่ผมได้เรียนรู้ : การใช้ if,else ได้อื่นหลายเเบบ ,การเขียนfont end เเละ back end ควบคู่, การเก็บข้อมูลในรู้เเบบ class ,def เพื่อให้ใช้ได้ง่ายหรือเรียกได้ง่ายขึ้น ,เเละอื่นๆอีกมากมายๆเเบบพื้นฐาน
